Both notebooks are standalone Python 3.11 or newer with the standard library. Open the `.ipynb` in Colab or an existing Jupyter environment, restart the runtime and run the cells in order after writing predictions. No install, credential or model account is required. Keep `RUN_LIVE = False` for the offline lesson. The cumulative book environment remains Python 3.14.

Notebook 1 separates response parsing, heuristic warnings and deterministic facts. Its live failure path labels a fixture fallback explicitly. Notebook 2 compares prompt wording and role placement, then validates structured drafts under a capability set, estimate constraint and model-call limit. Its optional live comparison retains failed attempts as failures; authored fixture rows do not measure prompt quality. Both lessons preserve the original shop during the Lime transfer exercise.

Submit predictions, a rejected request, a false claim outside the checker's coverage, a transfer case and an explanation of the Python boundary. Correct structured quantities do not certify an arbitrary model explanation. A system prompt does not change the host's purchasing authority or budget.

The downloads are versioned source artifacts, not a separate rendering location. Execution checks do not replace a hosted Colab rehearsal or a teacher's assessment of actual student work.
