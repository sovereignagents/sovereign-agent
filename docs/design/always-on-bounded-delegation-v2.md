# Catering tool interface after live construction

This supplements always-on-bounded-delegation-v1.md. Its assignment, budget, cancellation and worker decisions remain in force. Fourteen focused tests now include a model attempting to change the immutable inquiry.

The first real qwen3 run sent SKU and guest arguments to the original no-argument tool. Strict validation refused them, and the completed model loop left the work BLOCKED because no checked quote existed. The failed transcript is retained.

The tool now declares those two arguments through Inquiry and checks their exact equality with the stored assignment before calculating anything. The second live run produced a verified draft for forty-one guests: five tubs and GBP 25.00. It used two model calls, one tool call and 130 output tokens, taking about 4.3 seconds. The direct function took about ten microseconds in that local measurement and used no model calls. This is construction evidence, not a reliability rate or portable latency benchmark. Estimated inference cost was configured as zero; hardware and energy are not priced by that field.

Both complete transcripts, settings, model digest and final source digest are in delegation-live-construction-v1.json. No prompt change was made between those two runs. This evidence reinforces retaining the function for the fixed calculation while teaching the controlled delegation option. The full overhaul remains active.
